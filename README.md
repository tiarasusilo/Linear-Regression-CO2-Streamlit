# Linear-Regression-CO2-Streamlit
Aplikasi berbasis Streamlit untuk memprediksi emisi CO₂ kendaraan berdasarkan ukuran mesin menggunakan metode Linear Regression. Proyek ini mencakup proses pengolahan dan analisis dataset, pembuatan serta evaluasi model regresi, penyimpanan model dalam format .pkl, dan implementasi model ke dalam aplikasi web interaktif.
